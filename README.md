# 📚 API REST - Sistema de Biblioteca Escolar

Esta é uma API REST desenvolvida para a gestão de uma biblioteca escolar, permitindo gerir livros, estudantes e empréstimos. O projeto foi construído em Node.js com Express e armazena os dados em memória.

---

## 🚀 Tecnologias Utilizadas

- **Node.js**: Ambiente de execução JavaScript.
- **Express**: Framework web para criação das rotas e middlewares.
- **express-validator**: Middleware para validação dos dados de entrada.
- **nodemon**: Ferramenta para reiniciar automaticamente o servidor em desenvolvimento.
- **swagger-ui-express & yamljs**: Ferramentas para gerar a documentação interativa da API.
